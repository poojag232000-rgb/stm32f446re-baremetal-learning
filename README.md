# Cortex-M4F MSP432E401Y Learning Workspace

This repository is a GitHub-ready starting point for learning Cortex-M4F concepts on the MSP432E401Y board.

## Goals
- Build a strong understanding of Cortex-M fundamentals
- Practice bare-metal firmware development
- Create an interview-ready embedded portfolio project

## Roadmap
1. Bare-metal setup
2. GPIO and LED blink
3. Interrupts and NVIC
4. SysTick
5. UART
6. ADC and PWM
7. Fault handling and SCB basics
8. Final portfolio project

## Project structure
- src/ - source files
- include/ - headers
- ld/ - linker script
- docs/ - topic notes and study material
