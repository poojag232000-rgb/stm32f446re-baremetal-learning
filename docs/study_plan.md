# Study Plan

## Topic 1: Bare-metal startup
- Understand the reset vector and startup flow
- Learn the role of the linker script
- Build a minimal project

## Topic 2: GPIO
- Configure an LED and button
- Practice register-based control

## Topic 3: Interrupts
- Enable NVIC interrupt handling
- Toggle outputs from an ISR

## Topic 4: SysTick
- Create periodic tasks

## Topic 5: UART
- Print debug logs

## Topic 6: ADC and PWM
- Read analog input and control output

## Topic 7: Fault handling
- Understand HardFault and SCB basics

## Topic 8: Final project
- Combine all topics into one embedded application
